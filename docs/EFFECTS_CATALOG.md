# Effects Catalog

system.

## Audio Channel Mapping — Prominence System

Effects are assigned to frequency bands for dynamic opacity via the
prominence levelTOP system:

| Band | Effect Slots | Opacity Expression |
|------|-------------|-------------------|
| Bass | 0-13 | `0.6 + bass * 0.4` |
| Mids | 14-28 | `0.6 + mids * 0.4` |
| Highs | 29-42 | `0.6 + highs * 0.4` |

All effects additionally receive a beat flash: `brightness = 1.0 + beat * 0.3`.

## Canonical Visual Techniques (7)

These are the 7 distinct visual techniques identified by k-means clustering
of 1,871 frames from the source video. Full details in
[reference/CANONICAL_CATALOG.md](../reference/CANONICAL_CATALOG.md).

| # | Technique | Coverage | Audio Mapping |
|---|-----------|----------|---------------|
| 1 | Chiaroscuro magenta bloom | ~45% | bloom_radius <- energy, aberration <- onset |
| 2 | Chiaroscuro cyan/cool bloom | ~12% | bloom_radius <- energy, temperature <- sub_bass |
| 3 | Crushed-black silhouette | ~15% | black_point_lift <- -1 * energy |
| 4 | Hazy low-contrast dream | ~3% | haze_opacity <- 1 - energy |
| 5 | Dark atmospheric macro | ~4% | macro_zoom <- energy, bokeh_size <- mids |
| 6 | Pixel-sort radial shards | ~3% | shard_length <- onset, radial_velocity <- kick |
| 7 | Feedback echo tunnel | ~7% | feedback_gain <- sub_bass, zoom_step <- beat |
